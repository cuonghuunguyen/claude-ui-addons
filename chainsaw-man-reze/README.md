# Chainsaw Man Reze

Theme for claude-ui. Fan-made, personal use. Characters and artwork belong to their owners.

- Blurred art background in light and dark, panels frosted over it, matching colours.
- Dancing-figure loader, rotating "Thinking" text, burning bomb while running, exploded bomb after a tick.
- Capabilities: none.

Images are files in `images/` (`bg-light.jpg`, `bg-dark.jpg`, `dance.webp`, `bomb.svg`, `boom.svg`), referenced from `theme.css` with relative `url()`. `icon-512.webp` is the addon icon.

Install: `/addons` > Local folder > this folder path > Approve and enable. The CSS applies while the addon is enabled; Settings > Appearance lists the palette as "Chainsaw Man Reze".
