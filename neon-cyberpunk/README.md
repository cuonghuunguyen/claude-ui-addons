# Neon Cyberpunk

Theme for claude-ui. Cyberpunk HUD: navy-black (dark) / pale blue-white (light) surfaces, cyan primary, magenta keywords. Cut-corner glass panels, rain, sign flicker, tab glitch, rotating conic border on the focused prompt box. Capabilities: none.

Art is original (generated SVG): night city (dark), dawn city (light), rain layers. Files in `images/`, referenced from `theme.css` with relative `url()`.

Install: `/addons` > Local folder > path of this folder > Approve and enable. Then Settings > Appearance > Neon Cyberpunk.

Replaceable layers (CSS custom properties on `:root[data-theme="addon:neon-cyberpunk:neon"]`): `--neon-art`, `--neon-flicker`, `--neon-veil`, `--neon-glass`. The addon `neon-city` uses them to put pictures behind the theme.
