# Reze addon

Theme "Reze" for claude-ui. Fan-made, personal use. Images are not included: add your own to `images/`.

| File | Use | Size |
| --- | --- | --- |
| `images/bg-dark.jpg` | Dark mode background | 1920×1080 or larger, dark, subject off-center |
| `images/bg-light.jpg` | Light mode background | 1920×1080 or larger, bright |
| `images/mascot.png` | Sidebar icon | ~256×256, transparent PNG |

Install: `/addons` > Local folder > this folder path > Approve. Pick Settings > Appearance > Reze.
